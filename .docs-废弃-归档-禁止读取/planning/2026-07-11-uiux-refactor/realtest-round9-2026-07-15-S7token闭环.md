## A. 幽灵 token 修复（两处用户可见 bug，最高优先）

- [x] **文件大小徽章有底色了**：设置 → 缩略图信息 → 勾 **文件大小** → 画廊缩略图右下角出现
      `12.3 MB` 类徽章，**底色为半透明黑**（`rgba(0,0,0,0.6)`）。
      修复前：`--color-badge-size` 六主题均未定义且无 fallback → 底色全透明 → 白字直接压在照片上，
      浅色照片上几乎读不出。**六套主题都要看**（此 bug 与主题无关，全中）。
- [x] **DOM/canvas 两路同色**：开 canvas 网格实验开关（DEV + localStorage debug flag）→ 同一批图对比
      DOM 网格与 canvas 网格的大小徽章底色**一致**。修复前 canvas 因带 de-facto 回落值反而是对的、
      DOM 是坏的，两路分叉。
- [x] **粘性分隔胶囊不再是白条**：切到 **Ink / Obsidian / Dai**（暗色主题）→ 画廊按日期/文件夹分组滚动 →
      顶部粘住的分组标签胶囊底色应为**主题暗底**半透明，不是白色。
      修复前 `rgba(var(--color-bg-primary-rgb, 255,255,255), .85)` 回落写死白色 → 四套暗色主题下白条刺眼。
- [x] **性能面板红色态**（devtools）：打开性能面板 → 录制态/错误态的文字与底色应为**主题 error 红**。
      修复前 `var(--color-danger)` 无 fallback → `color` 回落继承色、`color-mix` 整条声明失效 → 一直没红出来。
- [x] **书签删除键 hover 变红**：文档阅读器 → 书签面板 → 悬停条目删除键 → 变**主题 error 红**（随主题走，
      不再是写死的 `#d9534f`）。
- [x] **H-Lab 视图衬底随主题**（dev）：`/hlab` → 根衬底随主题变（不再恒为写死 `#111`）。六主题各切一次。

## B. AUDIO / DOC 类型角标（新产品 UI）

> 显示模型：**总开关 `showThumbInfo` 本轮默认改开**（此前默认关，导致元素勾选面板被 `v-if` 藏住、
> 整套逐元素配置不可发现）；`type` 元素键**默认不勾**（与其余 10 项一致）。
> 故**升级后缩略图观感应零变化**，直到用户主动去勾。

- [x] **元素面板默认可见**：全新配置（或清 `show_thumb_info` 配置项）启动 → 设置 → 缩略图信息悬浮窗
      **开关默认开**，其下的元素勾选框（状态图标/媒体类型/文件大小/…）**默认全部未勾**。
- [x] **默认观感零变化**：上述默认态下，画廊缩略图上**不应出现任何徽章或信息行**（LIVE / 相似度除外，
      二者本就不受总开关管）。若出现了，说明默认 elements 非空 —— 与设计不符。
- [x] **显式关过的用户不受影响**：曾在设置里手动关掉总开关 → 升级后**仍是关的**（配置读回覆盖默认）。
- [x] **AUDIO 角标**：勾 **媒体类型** → 音频文件缩略图角标行出现绿底白字 `AUDIO`。
- [x] **DOC 只给有真实缩略图的文档**：勾 **媒体类型** → **PDF / SVG / 有封面的 epub** 出橙底白字 `DOC`；
      而 **txt / md / docx / xlsx / pptx / od\***（纸张卡）**不出** DOC —— 它们已自带扩展名角标
      （`MD` / `DOCX` 那个彩色小标），再叠 DOC 属重复标记。
- [x] **视频不出 VIDEO**：视频缩略图只有居中播放键 + 右下时长，**无 VIDEO 字样**（有意，不重复标记）。
- [x] **无封面 epub 不出 DOC**：封面提取盖棺失败的 epub 降级为纸张卡 → 走扩展名角标，**不出** DOC。
- [x] **canvas 网格同构**：canvas 网格下 AUDIO/DOC 角标的**出现条件与底色**与 DOM 网格一致
      （判定已走 `typeBadgeOf` 共享单源，此项验单源确实两路生效）。
- [x] **六主题徽章观感**：六套主题各看一次 AUDIO（绿）/DOC（橙）底白字压在照片上是否可读。
      注：徽章底色**随主题分亮暗两组**（暗色主题一组、亮色主题一组），与 LIVE 徽章同族。

## C. 占位符接线（视觉微变，有意）

- [x] **搜索框占位符变暗一档**：顶栏搜索框 + 设置页搜索框的占位符文字，应比修复前**略暗**
      （改用专属 `--color-text-placeholder`，此前误用 `--color-text-tertiary`）。
      六主题各看一次，重点确认**仍清晰可读**（`check:contrast` 硬门已过 ≥3.0，但那是算出来的，
      真机看观感）。
- [x] **对比度门从幻影变真门**：（无需操作，记录用）此前 `check:contrast` 硬门守着
      `--color-text-placeholder × bg-surface`，而占位符实际由 tertiary 渲染 —— 门在为不上屏的值背书。
      接线后该门对指向真实渲染值。

## D. 元数据白拉修复（性能，需观察 IPC）

- [x] **不勾 meta 类元素时不拉元数据**：设置只勾 **文件大小 / 状态图标 / 媒体类型**（纯 item 字段）→
      滚动画廊 → **不应**有 `get_meta_for_viewport` IPC 调用。
      修复前只看总开关 → 这些元素也每屏拉一遍 EXIF/GPS/路径，拉回来无人渲染。
      （本轮总开关默认改开，若不修此项 = 所有用户白付这笔开销。）
- [x] **勾 meta 类元素后正常拉**：改勾 **相机 / 拍摄参数 / 地理位置 / 文件名 / 路径** 任一 →
      滚动 → 信息行正常显示相应内容（说明 `get_meta_for_viewport` 确实在拉）。
- [x] **中途勾选立即生效**：先只勾 文件大小（不拉）→ 画廊静止不动 → 此时勾上 **相机** →
      **不滚动**也应在 ~120ms 内补拉并显示相机行。
      修复前元素列表不在 watch 源里 → 得等行变化（滚动）才补拉。

## E. 读屏（可选，与前几轮同类盲区）

- [x] AUDIO/DOC 角标的 `title`（音频文件 / 文档文件）在读屏下可达；角标文字本身作为卡片内容被读出。

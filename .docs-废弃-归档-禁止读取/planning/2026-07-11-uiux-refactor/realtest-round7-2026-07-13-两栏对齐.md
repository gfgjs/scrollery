> **②** 顶栏/选区栏默认靠中，增设置项可选**居中/靠左/靠右**(两栏各一)，收窄窗口先减留白、再折叠。
> 逻辑已过本地门禁(typecheck/lint/vitest 810/build)。以下为**门禁盲区**——对齐视觉/动画/收窄次序/

## A. 折叠 ⋯ 弹层：卡片弹出 + 居中对齐（需求 1）

- [ ] **选区条 ⋯ 上弹居中**：浮动/停靠选区条收窄折出 ⋯ → 点 ⋯ → 菜单在按钮**正上方居中**弹出
      (placement=top，非此前右缘对齐 top-end)；动画自按钮处**向上「生长」**(scale 0.95→1 + 从下 8px 滑入)，
      呈卡片弹出观感，不再从画面左侧飞入。
- [ ] **顶栏筛选/视图 ⋯ 下弹居中**：顶栏收窄折出筛选 ⋯ / 视图 ⋯ → 点开 → 菜单在按钮**正下方居中**弹出
      (placement=bottom)；动画自按钮处**向下生长**(从上 8px 滑入)。
- [ ] **近视口边缘不越界**：⋯ 按钮靠近屏幕左/右缘时，居中菜单若会越界 → @floating-ui shift 自动推回视口内
      (此时动画原点略偏离按钮属可接受，居中是「有空间即居中」)。
- [ ] **date 弹层无回归**：日期筛选弹层定位仍准、自按钮生长、无 (0,0) 左上角闪现。
- [ ] **六主题**：卡片弹层表面(bg/border/shadow)与动画在 6 主题下正常。

## B. 顶栏 chips 簇对齐（需求 2·顶栏）

> 顶栏三区：标题(恒左) | 筛选/视图 chips 簇(中部折叠区) | 搜索(恒右)。对齐只挪**中部簇**。

- [ ] **默认居中**：全新启动(或清 localStorage)→ 顶栏 chips 簇**居中**显示，两侧留白；标题仍贴左、搜索仍贴右。
- [ ] **设置切换**：设置→界面→「顶栏工具对齐」下拉选 居中/靠左/靠右 → chips 簇即时改位
      (靠左=贴标题侧、右侧留白；靠右=贴搜索侧、左侧留白)；标题/搜索**不动**。
- [ ] **先减留白再折叠**：居中态缓慢收窄窗口 → 先看到两侧留白**收缩**(簇整体保持、不折)→ 留白吃尽后才开始
      从尾折入 ⋯。靠左/靠右同理(先吃单侧留白)。
- [ ] **持久**：选定对齐 → 关 App 重开 → 顶栏对齐保持(localStorage `toolbar_align`)。

## C. 选区浮动胶囊对齐（需求 2·选区栏）

- [ ] **默认居中**：多选出浮动胶囊 → 默认**水平居中**(现状)。
- [ ] **设置切换**：设置→界面→「选区操作条对齐」选 靠左/靠右 → 胶囊**默认停靠位**移到该侧
      (距边界约 12px 呼吸，不贴死边缘)。
- [ ] **对齐=默认位、拖拽仍可覆盖**：选靠左后，胶囊仍可**拖拽**微调并持久化(上轮 C4);再改对齐 → 旧拖拽偏移
      **被清空**、胶囊回到新对齐的静止基位(防基位变后偏移把胶囊推到屏外)。
- [ ] **非对称钳制不失踪**：靠左态把胶囊尽力往**左**拖 → 只能到边界留边(几乎不动)；往右拖 → 可拖很远。靠右
      镜像。任何对齐 + 缩小窗口 → 胶囊被钳回完整可见、拖拽手柄可达。
- [ ] **收窄先减留白再折叠**：靠左/靠右态收窄窗口 → 先吃该侧留白，再由折叠引擎从尾折入 ⋯。
- [ ] **持久**：对齐跨重启保持(localStorage `selection_bar_align`)。

## D. 两栏独立 + 与既有设置共存

> 🟢 **round7 后续修复(见 progress/findings 会话续22)**：真机报「docked 态对齐未生效」——原因是 round7 只把对齐
> class 挂到浮动壳 wrapper，漏了 docked 这条 Teleport 渲染分支。已补:SelectionActions 在 docked 变体上对填满
> outlet 的 `.selection-actions` 施 justify-content。**下方「与停靠共存」项由「docked 属范围外」改判为「docked 同样生效」。**

- [ ] **两栏各一**：顶栏对齐与选区栏对齐**互不影响**(顶栏靠左 + 选区居中可共存)。
- [ ] **与停靠/合并共存(docked 态对齐现已生效)**：selectionBarDocked 开(停靠状态栏)+ 选区态时，改「选区操作条对齐」
      → docked 动作簇在状态栏 outlet 区(左侧、版本号之前)按对齐落位:居中→簇居 outlet 中;靠右→簇贴 outlet 右缘
      (版本号左侧);靠左→贴左(默认)。切回浮动保持同一对齐。
      注:居中/靠右是在 **outlet 可用轨道**内对齐，非整条状态栏几何中心(版本号 v0.1.0 恒在最右，属预期)。
- [ ] **docked 收窄先减留白再折叠**：docked 居中/靠右态缓慢收窄窗口 → 先看 justify 留白收缩(簇整体保持)→ 留白吃尽
      后才从尾折入 ⋯，与浮动态一致(折叠流 flex-grow:0，自由空间只进 justify 不进流内)。
- [ ] **设置项就位**：设置→界面 节可见「顶栏工具对齐」「选区操作条对齐」两下拉，各三选项文案正确(中/英)。

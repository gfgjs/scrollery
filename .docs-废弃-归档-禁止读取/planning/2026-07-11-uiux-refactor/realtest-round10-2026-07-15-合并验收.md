## 7. 视图路由化 + URL 同步〔round8〕

> ## ⚠️ 2026-07-16：本节此前**不可测**，已重写验证手段
>
> 原文通篇写「地址栏变 X」「地址改成 Y 回车」——而 **Tauri WebView 没有地址栏**。用户如实回报
> 「APP 内无地址栏，无法测试」。**这是清单的缺陷**：写的不是代码的事实，而是我脑子里的假设（假设了
> 浏览器）。与本清单头部纠正的「过期预期」同族——那次是**预期**脱离代码，这次是**手段**根本不存在。
>
> **改用 DevTools Console，零代码改动**（`tauri dev` 默认开着 DevTools）：
>
> 1. **F12** 或右键→检查，打开 DevTools，切到 **Console**。
> 2. 下方每处「地址栏应为 X」→ 在 Console 敲 `location.hash`，回车看返回值。
> 3. 每处「地址改成 Y 回车 / 深链」→ 在 Console 敲 `location.hash = 'Y'`。
> 4. 每处「刷新」→ `location.reload()`。
>
> 建议把 Console 停在手边，边操作 UI 边敲 `location.hash` 对读数。

### 7.1 视图路由化

- [ ] **smart-album 各占独立路径**：侧栏点「收藏/实况/最近/回收站/全部照片」→ 地址栏分别变
      `#/favorites` `#/live-photos` `#/recent` `#/trash` `#/`；画廊内容随之切换。
- [ ] **深链恢复 smart-album**：地址改成 `#/favorites` 回车（或刷新）→ 进入收藏视图，侧栏高亮收藏。其余三个同理。
- [ ] **folder 筛选态（模式B）→ `/folder/:id`**：分组设为「日期」或「无」时，侧栏点某文件夹 → 地址栏变
      `#/folder/<数字id>`，画廊筛成仅该目录；刷新后仍在该目录。
- [ ] **folder 滚动锚点态（模式A）不进 URL**：分组设为「文件夹」时，侧栏点不同文件夹 → 地址栏**保持 `#/`**，
      画廊平滑滚动到该文件夹段。这是有意的——滚动位置不该进 history。
- [ ] 🔴 **新增扫描根 / 移动文件夹后自动选中**：新增扫描根，或移动文件夹 → 自动选中该目录时地址栏应变
      `#/folder/<id>`（而非停在 `#/` 被回填成「全部」而丢选中）。**这是修的 clobber 点，重点验。**
- [ ] **前进/后退**：在 全部→收藏→某文件夹 间点几次 → 后退能逐步回上一个视图，视图与地址一致。
- [ ] **KeepAlive/滚动不回归**：全部照片滚到中间 → 切收藏 → 切回全部 → 滚动位置恢复、不重新加载闪白。
- [ ] **切视图清选区、同视图内改筛选/排序不清**：切视图选区清空（既有契约）；同一视图内改筛选/排序**不应**清选区。

### 7.2 view-pref（分组/排序/方向/布局）URL 同步

- [ ] **改 view-pref 即写 URL**：工具栏改「分组=文件夹 / 排序=文件名 / 方向 asc / 布局=宫格」→ 地址栏出现
      `?group=folder` `sort=filename` `order=asc` `layout=grid`（**仅非默认值出现**；全默认时 URL 干净无这些键）。
- [ ] **深链恢复**：地址改成 `#/?group=folder&sort=filename&layout=grid` 回车/刷新 → 画廊按该分组/排序/布局呈现。
- [ ] 🔴 **URL 覆盖 persist**：先在设置里把默认分组设为「日期」（持久化）→ 用带 `?group=none` 的 URL 深链进入 →
      画廊显示「无分组」（URL 权威覆盖持久值）；去掉 URL 的 group 键刷新 → 回落持久的「日期」。
- [ ] **order 跨刷新恢复**：切排序方向 → URL 出现/移除 `order=asc` → 刷新后方向保持
      （sortOrder 无持久化，**只有 URL** 能跨刷新恢复它）。
- [ ] 🔴 **语义搜索不污染 view-pref URL**：进语义搜索 → groupBy 被临时改「无分组」，但地址栏**不应出现
      `group=none`**；退出语义搜索 → 分组复位、URL 恢复真实值。**语义搜索 开→关→刷新，分组应回到语义前的值，
      不卡在「无分组」。**

### 7.3 search（查询/范围/模式）URL 同步 ⚠ 高风险

- [ ] **提交搜索即写 URL**：普通/文件名搜索提交 → 地址栏出现 `?q=<词>`（及非默认 `scope=`/`mode=`）；
      清空搜索 → 相关键从 URL 移除。
- [ ] **深链恢复普通搜索**：`#/?q=IMG&mode=normal` 刷新/深链 → 恢复为文件名搜索「IMG」，结果正确。
- [ ] 🔴 **深链恢复语义搜索（触发 IPC）**：`#/?q=猫&mode=semantic` 深链/刷新 → **恢复时真实执行语义搜索**
      （不是只改地址不查询），画廊出语义结果。**重点：AI worker 未就绪时不崩、有 loading、
      最终出结果或明确错误（不静默失败）。**
- [ ] **scope 恢复**：文件名搜索把范围切到「目录/日期/设备/地理位置/全局」→ URL 出现 `scope=folder` 等 → 刷新恢复。
- [ ] **mode 恢复副作用正确**：`#/?q=x&mode=semantic` 深链进入 → 退出语义 → 分组复位到深链时 URL 里的值
      （或持久默认），**不卡在「无分组」**。
- [ ] **恢复顺序**：`?group=folder&q=y&mode=normal` 复合 URL → 恢复后既是文件名搜索「y」又按文件夹分组，
      两者共存不互相冲掉。

### 7.4 组合 / 回归

- [ ] **三者共存**：`?favorite=1&group=folder&q=z&mode=normal` → 收藏筛选 + 文件夹分组 + 文件名搜索「z」
      全部生效，刷新后全部恢复，互不冲掉。
- [ ] **URL 干净性**：回到默认（无筛选/默认分组排序布局/无搜索）→ 地址栏应为干净的 `#/`（或 `#/favorites` 等
      纯路径），**无残留空 query 键**。
- [ ] **collection/person 详情不受影响**：进 `#/collections/:id`、`#/persons/:id` → view-pref/search 仍可用；
      语义搜索面板只在主库血统视图显示（与拆分前一致）。
- [ ] 🔴 **无控制台报错/无死循环**：全程 Console 无 vue-router 重复导航告警、无 URL 抖动（反复 replace）、
      无 Duplicate keys。

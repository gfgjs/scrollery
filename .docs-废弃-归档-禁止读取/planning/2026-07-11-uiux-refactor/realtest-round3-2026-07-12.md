## A. Collections 删除 undo(软删除,73b698a)

- [ ] 合集页,删除一个**用户自建**收藏夹(先往里加几张图):确认框确认后,右下角应出现**「已删除「X」」** 的 toast,带**「撤销」** 按钮(5 秒)。
- [ ] 点 toast 的**撤销**:该收藏夹应**重新出现**在合集页,**且其中的图仍在**(成员未随删除丢失)。
- [ ] 不点撤销(等 toast 消失):收藏夹从列表消失;**刷新/重进合集页也不再出现**(软删除项被 list 过滤)。
- [ ] **系统夹**(图片/视频/音频/文档收藏)**无删除按钮**,不受影响。
- [ ] 删除后进过该夹的深链 `/collections/:id`:属既知边界(软删项路由未特判),正常回退到合集页即可,不应崩。

## B. Persons ignored 历史管理(误检桶,a5dc9ce)

- [ ] 人物墙,把某个「人物」**标记为误检**(Ban 图标 → 确认):该人物离开墙,头部出现**「已忽略 (N)」** 按钮(N=误检桶人数)。
- [ ] 点**「已忽略 (N)」**:切入误检桶视图,应列出所有已忽略的人物;卡片上只有一个**「移出误检桶」** 按钮(RotateCcw 图标),**无**选择/隐藏/误检按钮。
- [ ] 点某卡片的**「移出误检桶」**:该人物**恢复上墙**,toast 提示「已移出误检桶」;桶计数 N 减 1。
- [ ] 移出最后一个后:自动**切回人物墙**(showIgnored 关),「已忽略」按钮消失。
- [ ] **两切换互斥**:同时存在隐藏人物与误检桶时,「显示已隐藏」与「已忽略」点一个即关另一个,合并选区被清。
- [ ] 误检桶视图下:**审批建议 / 重新聚类** 按钮不显示(墙专属动作)。

## A. 分离(浮动)形态 —— parity 与拖拽持久化（C1/C4）

- [ ] **视觉 parity**:多选后浮动胶囊出现,动作图标顺序与改造前一致(全选/反选/收藏/取消收藏/加收藏夹/
      色块/清除色/删除 · 移动/复制 · 停靠切换 · ✕);hover 高亮、危险删除红色、tooltip 上方弹出均如常。
- [ ] **色块设色**:点色块给选区设色、Ban 清除色 —— 与改造前一致(数据驱动 commands 未破 parity)。
- [ ] **拖拽顺滑**:拖拽手柄拖动胶囊,跟手无卡顿、无跳变;拖拽中禁过渡(is-dragging)。
- [ ] **位置跨重启恢复**:拖到某处 → 关闭 App 重开 → 再多选 → 胶囊回到上次位置(localStorage 持久,
      **不再**「退出选区即复位」)。
- [ ] **小窗口 clamp 不失踪**:大窗口把胶囊拖到最左/最右/最上 → 缩小窗口再多选 → 胶囊被钳回**完整可见**、
      拖拽手柄可达(不卡在屏外);拖拽结束/窗口 resize 时也各自钳一次。

## B. 收窄折叠（C2）

- [ ] **逐项折入 ⋯**:拖窄窗口(或让内容挤压胶囊可用宽)→ 命令从**尾部**(复制→移动→删除…)逐个折入 ⋯ 菜单;
      ⋯ 按钮仅在有溢出时出现。
- [ ] **无振荡**:在临界宽度附近缓慢拖动窗口 → 不出现「折了又弹回、反复横跳」的抖动。
- [ ] **变宽自动回弹展开（round6 #1 修复复验）**:窄窗口把命令折进 ⋯ → **不刷新页面**、直接把窗口拉宽 →
      命令**自动逐个弹回**、⋯ 在无溢出时消失。(修前症状:折叠后拉宽不回弹须刷新;根因=内容宽折叠流 RO 失联,
      改走 window resize→完整 measure。)
- [ ] **⋯ 菜单上弹 + 自按钮生长(round6 #3 修复复验)**:点 ⋯ → 菜单在按钮**正上方居中**弹出
      (`placement="top"`,条在底部),且动画**自 ⋯ 按钮处向上「生长」弹出**(scale from 按钮那条边),
      **不再**从画面左侧/左上角飞入;近视口边缘时由 flip/shift 自动翻转/推回,不越界出屏。
      🔴 **本项原文已过期并更正**:本轮落地时为 `top-end` 右缘对齐,**已被 round7「居中对齐」需求推翻**
      (`SelectionActions.vue:107` 现为 `placement="top"`)。照原文「右缘对齐」测会报出假 bug。
- [ ] **菜单内色签行**:溢出集含色块单元时,菜单里整行渲染 ColorLabelPicker(图标 + 「颜色标签」+ 一排色块),
      点色块即设色并关菜单。
- [ ] **菜单行可见文字标签**:每个折叠命令在菜单里都是「图标 + 文字标签」(兑现主设计 §7.1 可见标签 a11y 改进);
      删除行红色。
- [ ] **焦点陷阱**:⋯ 菜单打开后焦点入菜单,Tab/Shift+Tab 在菜单项间循环不逃逸;Esc 关闭;点 backdrop 关闭;
      关闭后焦点归还 ⋯ 按钮。
- [ ] **容器变宽自动关空菜单**:菜单开着时拉宽窗口使溢出集清空 → 菜单自动关闭(hasOverflow 转 false)。

## C. 合并(docked)形态（C3）

- [ ] **切换到 docked**:点胶囊上「停靠到状态栏」(PanelBottom)→ 胶囊消失,操作并入**底部状态栏左侧**;
      状态栏原「N 项 · 图 · 视频」info **让位**、右侧版本区(v0.1.0)**保留**;28px 行高不变、**网格无 reflow**。
- [ ] **docked 命中区**:状态栏内动作按钮 24×24,点击手感正常、图标 14px 清晰;计数「已选择 N 项」左侧显示。
- [ ] **docked tooltip 不裁**:hover docked 按钮 → tooltip 在其上方弹出、**不被状态栏裁切**。
- [ ] **docked 折叠**:窄窗口下 docked 条同样从尾折入 ⋯(28px 行更早触发);⋯ 菜单仍上弹(状态栏在底,向上够空间)。
- [ ] **docked 变宽自动回弹展开（round6 #2 修复复验）**:docked 态窄窗折叠命令 → 拉宽窗口 → 状态栏内命令
      **自动逐个弹回**、⋯ 消失(与浮动态同机制:内容宽 flow 走 window resize→measure)。
- [ ] **切回浮动**:点 docked 条上「浮起为胶囊」(PanelTop)→ 回浮动胶囊,状态栏 info 恢复。**切换全程选区不丢**。

## D. 一键切换双入口同源（C3）

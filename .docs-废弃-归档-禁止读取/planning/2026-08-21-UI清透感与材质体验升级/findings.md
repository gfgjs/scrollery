# 发现与决策:UI清透感与材质体验升级

## 需求
- 用户反馈：“总感觉 UI 整体不好看且不够‘清透’，但具体哪儿不好看又说不上来，整体分析下 UI，看看最可能是哪儿的问题”。
- 在新建专项分支 `feat/ui-clarity-upgrade` 上制定施工计划并逐步落地。
- 用户进一步要求：“现有的主题配色也不好看，蓝紫配色显得很土。4个蓝色系太多了，其中3个换成粉金、淡绿、天青”。

## 发现
1. **“闷”的病因**：卡片与浮层使用纯单层暗色描边（`border: 1px solid var(--color-border)`），缺乏现代 UI 常见的顶部内高光微反光（Rim Light），导致材质呈现出实心塑料块的厚重与封闭感。
2. **“碎”的病因**：设置页与多处模块出现多层容器嵌套（卡片外框套分组框套行框套控件框），过度依赖 1px 线条区分层级，导致整体被切割成蜂巢状。
3. **“脏”的病因**：纯黑色 Alpha 阴影（`rgba(0,0,0,...)`）打在冷白或冷蓝灰（Moonlight）底色上时会产生灰脏感，缺乏与主题背景色相调和的漫反射软阴影。
4. **“噪”的病因**：顶栏多个 Filter Chips 在未激活时也常驻实体边框与底色，形成密集胶囊阵列，视觉噪声过大。
5. **“土”的病因**：原主题中 3 套主题（Porcelain / Ink / Obsidian）过度滥用 Tailwind 荧光蓝紫（Indigo `#6366f1` / `#818cf8`），带来廉价模板感，且缺乏色彩独立性与东方意境。

## 关键决策
<!-- 需收口提升的决策编 D-001 递增填「候选 ID」列;仅会话内有效的留空 -->
| 决策 | 理由 | 候选 ID |
|------|------|---------|
| 采用单一 main 原生窗口 + HTML 启动层 | 复用同一个原生窗口才能消除尺寸、位置、焦点、任务栏身份和材质切换 | D-001 |
| 启动动画使用不确定进度环/呼吸点，不显示虚假百分比 | 当前启动链路没有可靠的阶段权重，虚假百分比会造成停滞感 | D-002 |
| 启动层使用 index.html 静态标记 + 外部经典脚本 | 首帧不依赖 Vue/入口 bundle，同时遵守生产 CSP，不另建同视觉 Vue 组件 | D-003 |
| 启动层置于 body 第一节点并自持首帧颜色变量 | 让原生窗口首次可见到静态层之间只保留同一张 loading surface，避免 #app 或全局模块 CSS 到达时触发闪烁 | D-004 |
| 主窗口须在 AppState 注入且原生材质同步挂载后才显示 | 过早 show 会让 WebView 抢跑 IPC，导致 `data-glass` 水合失败；异步材质投递无法保证首个可见帧不是透明窗口 | D-005 |

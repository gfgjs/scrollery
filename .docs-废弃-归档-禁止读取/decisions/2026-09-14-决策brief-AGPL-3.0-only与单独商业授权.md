# 决策 brief:第一方公开源码改为 AGPL-3.0-only 并单独提供商业授权

> 本文是 2026-09-14 许可决议的存证,也是本线「第一方公开源码许可」范围内的当前答案。
> 本文只记录许可决议,**不构成发行放行**:渠道过滤、第三方归属、安装包与收费闭环的既有待办按
> [渠道与开源边界滚动状态](../status/渠道与开源边界.md) 另行验收。

## 结论

自本次实施提交起,Scrollery 第一方公开源码统一采用 **GNU Affero General Public License
version 3 only**(SPDX: `AGPL-3.0-only`);正文使用 GNU 官方英文原文,**不做任何修改**,仓库根
`LICENSE` 即该许可的权威副本。

版权人同时另行提供**单独商业授权**。两条路径并行:任何主体都可以只依赖 AGPL 行使权利,
**不需要购买商业授权**;普通商业使用不因此被设定为必须付费。商业授权涵盖官方商业版的
终端用户许可,以及企业/OEM或闭源服务所需的替代条款,不是行使 AGPL 权利的前提。

## 范围

- 覆盖公开镜像投影的全部第一方源码:前端 `src/`、Rust 主机 `src-tauri/`、随附现有 worker、
  授权实现(含 keyring 直销授权与 Ed25519 验签)、插件平台契约与构建/发布脚本。**公开源码
  统一许可**,不按功能模块区分许可。
- 未进入公开镜像的私有内容不因本文获得该许可。未来新开发的独立商业组件是否公开另行决定;
  一旦其源码进入公开镜像,同样适用 `AGPL-3.0-only`。
- 第一方版权由版权人持有(2026-08-25 确认,2026-09-14 复议维持)。第三方依赖、vendored
  资源、上游模型与材料不进入本决议,继续按各自原始许可分发;`NOTICE.md` 为生成物,不机械改写。
- 已按 MPL-2.0(及更早 Apache-2.0)取得副本、fork 或发布物的主体,其既有权利不因本次
  变更而撤销或收紧;历史发布物与历史许可记录保留为当时的真实状态。

## 第 13 条与 NAS Server / Web

AGPL 第 13 条要求:修改版若通过网络向用户提供交互服务,须向这些用户提供取得对应源码的机会。
该义务的适用对象是**按 AGPL 运行、且落入第 13 条范围的修改版**;未经修改地使用本项目的
第三方依赖仍按各自原始许可处理,不因本决议改变。
NAS Server / Web 目前只是规划中的路线,**当前不存在已发布的服务端实现,也不存在配套的源码下载
或提供设施**;本文不声称这类设施已经具备。该义务在本项目实现并对外提供上述服务时由发布方落地,
对应要求已并入渠道滚动状态的既有发行待办。
版权人就其覆盖的第一方源码另授商业许可时,可以同时给出不同于 AGPL 的替代条件;该许可只作用于
版权人有权许可的第一方部分,不改变第三方依赖、vendored 资源与上游材料的原许可。

## 商业许可

- 商业授权与 AGPL 并行,由版权人分别签发;条款、价格、席位与适用法域以正式商业协议文本为准,
  本文不预设、不编造。
- 商业范围包含两条彼此独立的路径:**官方商业版**面向普通终端用户(个人或公司),通过购买取得
  AGPL 之外的使用条件,以终端用户许可协议(EULA)承载;**OEM / 闭源服务授权**面向厂商、集成方
  或需要以闭源方式集成、再分发或对外提供服务的合作方,通过单独签署的 OEM 协议取得相应权利。
- 两类协议范围不同、互不替代,但不要求同一方同时签署两份:终端用户接受 EULA 并满足其约定条件后取得商业授权,OEM
  协议按需单独签约;不存在「每个用户都要另做一次纸质签约」的要求。

## 贡献与再许可

- 未来外部贡献须通过 CLA 授予有效且充分的商业再许可授权,使版权人能够在不同条款下分发
  整个项目(含商业授权)。
- `CLA.md` 本次实际修订为 **1.1 版(生效 2026-09-14)**:第 2 条区分维护者的再许可/商业许可权
  与接收者按项目分发许可行使的权利,并明确签署绑定本版本、先前版本的签署记录不延伸至本版。
  该版本面向未来生效的同意,不追溯取消已授出的权益,也不改变既有贡献者按当时许可已取得的权利;
  维护者合并前须核验贡献者对本版的有效同意。

## 与旧决议的关系

本决议取代 2026-09-12「主程序第一方源码统一 MPL-2.0」的许可结论,以及 2026-08-25
「Apache-2.0 → MPL-2.0」迁移作为**当前第一方许可**的地位。旧决策与审查正文按其日期保留证据,
仅在文首标注许可结论已被本决议取代。第三方许可、已发布旧版本许可与历史记录不变。

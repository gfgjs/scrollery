## 0. 先买断时间压力(建议今天做,与终选解耦)

三次抢注实证(scrolio.app 差 11 天 / scrollary 双域差 5 天 / foteca.com 已放弃)表明:候选名的域名坑位以**周**为单位消失。对策不是急着拍板,而是**先花小钱把仍空闲的坑位占住**,再慢慢想:

| 动作 | 成本 | 效果 |
|---|---|---|
| 注册 scrolleria.com + scrolleria.app | ~$30/年 | 锁住推荐组合的英文坑位 |
| 注册 handscroll.app(+可选 scrollery.app) | ~$14/年·个 | 锁住保守选项(和/或心头好)的坑位 |
| GitHub 建 org:scrolleria(+handscroll-app) | 免费 | 锁 org 名 |
| handscroll.com 挂 drop-catch(08-19 到期) | ~$70 成交才收费 | 期权 |

全套 ≈ **$60-120/年**,买到的是「终选可以想多久都行」。域名闲置一年弃掉即可,沉没成本可忽略。
(crates.io 依其政策**不预占**;中文名无坑位可占,CNIPA 委托检索本就是律师环节。)

## 2. 各组合再多说三句

**Scrolleria / 卷廊**:唯一「英文全绿 × 中文近全绿」。设计思路=「注册名 ≠ 传播名」:商标要显著性,情感属于文案层——「画卷」以 slogan(如「把照片铺成一幅画卷」)、首启动画、时间轴隐喻的形态出现在每个用户面前,不牺牲注册性。风险实质只有一个:品牌含义要自己灌注(所有伟大的生造名——Kodak/Sony/Picasa 本身——都走过这条路)。

**Scrollery / 画卷**:情感分最高,法务上也过得去(商标面唯一近邻是 41 类休眠学者标)。要价是三笔长期税:开发者搜 scrollery 先见两个 JS 库;App Store 中国区与「画卷-拼图」共存(且若对方先注 9 类商标存在投诉风险);中文口碑传播后用户搜「画卷」找不到你。如果你对「获客靠商店编辑推荐/社群口碑直链而非搜索」有信心,这些税可以认。

**Handscroll / 长卷**:商标面最保守的选择,文化叙事(手卷式横向浏览,恰是 H-Lab 的产品事实)完整。短板是英文名对中文用户无感、中文名「长卷」平淡,组合的「品牌温度」靠视觉设计补。

**Scrolio / 长卷**:仅当你极度看重短名时考虑;.app 被抢注者 11 天前拿走且意图不明,这个悬念本身就是扣分项。

> **追加筛查(2026-07-06)**:用户提名 **MyScrolls 🔴 已否决**——坑位近全绿但商标面撞死:ZeniMax 2024 官方清单仍在权持有标准字 SCROLLS(v. Mojang 和解=该商标全归 ZeniMax)+对小体量目标的习惯性 C&D 史;"MY-" 属两局实务公认弱前缀救不了 dominant element;itch.io 另有 exact 同名在售图像软件。全证据见[初筛文档 §7.6](2026-07-05-R2-7-产品名初筛与改名面盘点.md)。四组合格局不变。

## 3. 拍板后的固定流程(选谁都一样)

1. 当天:补齐所选组合的域名/org(若 §0 已做则跳过)。
2. 我出 FTO 律师 brief 终稿(含该名特定问题清单)→ 你委托三辖区检索(US/EU/CN,$1500-4000,数周)。
3. FTO 绿 → 提交商标申请(9+42 双类,CN 含中文名)→ 改名施工(identifier 锁定 `com.<name>.app` + keyring 迁移 + D10 门禁 CI + 全仓替换,我出施工计划,约一个工作日)。
4. FTO 红 → 退回本页选下一个(域名沉没成本 ~$15-30)。

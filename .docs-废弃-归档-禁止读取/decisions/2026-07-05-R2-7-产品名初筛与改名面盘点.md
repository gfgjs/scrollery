## 2. 用户新提名评估(2026-07-05 会话内)

'Scroll' / 'Scroll Photo' / 'Photo Scroll':**均不建议进入 FTO 名单**。
- Photo 组合词:违反 §10.7 第一判据(不绑 photo 词根,四媒体产品);描述性组合=最弱商标。
- 'Scroll' 单词:显著性天然残废(命名的恰是产品核心交互=描述性);已知重量级占位(Scroll zkEVM/scroll.io 在营、scroll.com=Twitter 收购遗产、crates.io `scroll`=Rust 著名字节解析库)〔以上凭知识库,未跑正式筛,标注待核〕;Steam 渠道有 ZeniMax 对 "Scrolls" 的执法先例(Mojang 案,2012 和解);SEO 不可搜索,与 Part8 Star 漏斗获客策略冲突。
- **「卷轴」意象本身有价值**(暗合 H-Lab 横向长卷浏览+中国画手卷),若取意象走造词化路线(coined derivative)另筛。

## 3. 初筛沉淀的判据硬化(第七轮起生效)

候选名过预筛的**新增硬门槛**(Mnemo 教训:生态可得性=先决而非加分):
1. crates.io 裸名可用(Rust 项目撞裸名难看且 SEO 吃亏);

4. Steam/Microsoft Store 站内 0 同名(目标渠道);
5. 中文音译空间预检(避开特斯拉/尼莫类强联想污染)。
命名窗口实时收窄的实证:Mnemo 的 99 段申请、Tessera Labs(2025)、Lumeo AI Search(2025 末)均为第六轮定稿**之后**出现的占位者——拖延成本单调上升不是修辞。

## 4. 改名爆炸半径盘点(identifier 锁定输入,2026-07-05 grep 实证)

### 4.1 运行期状态坐标(纯替换会丢用户数据,须迁移或趁内测期改)
| 面 | 现值 | 后果与对策 |
|---|---|---|
| tauri `identifier` | `com.picasanext.app`(tauri.conf.json:4) | 决定 appDataDir → 图库 DB/缩略图/已装插件孤儿化。趁**现内测期**改=通知重装;上架后改=全量迁移代码+商店重上架丢评分 |

| MSI 升级谱系 | 随 identifier/productName 断裂 | 内测机器卸载重装即可 |

### 4.2 机械替换面(编译期/物料,无状态风险)
- Cargo 包名族:`picasa-next` + 5 个 `picasa-next-*` crate + `picasa_next_*` lib 名;package.json name。
- `productName:"Picasa Next"` + 窗口 title ×2 + i18n 品牌串(zh/en 各 4)+ README/NOTICE/CHANGELOG。
- `PICASA_*` 环境变量族(~10 处,纯内部约定,可入 D10 allowlist 缓改)。
- GitHub 三仓(picasa-next / -private / -registry)+ 内测 registry raw URL(脚本 1 处 + Rust DEFAULT_REGISTRY_BASE 常量)。
- 域名:**未购,零沉没成本** ✓。

### 4.3 D10 改名门禁设计要点(定名后实施)
- CI 断言范围=代码标识符/productName/identifier/Cargo·package 名/模块前缀/物料;**allowlist 豁免** plan-docs/历史文档/SEO 自然提及(Part8 P1-11:非全仓裸 grep)。
- identifier 定式 `com.<newname>.app`,首次对外分发前锁定,锁定后永不变更(RK4)。

### 7.6 单名追加筛查:MyScrolls(用户提名,2026-07-06,2 路)

**裁决:🔴 淘汰。** 生态坑位罕见地近全绿,却在商标面撞上本项目筛过的所有候选里最硬的一堵墙——是「坑位可得性 ≠ 可注册性」的最佳教材案例。

**坑位面(六硬门,近全绿)**:crates/npm/PyPI(含连字符变体)全 404、GitHub user/org 404、**myscrolls.app 未注册**(Google Registry RDAP 直查)、Steam storesearch `total:0`、App Store/Play 搜索级零命中。仅两处碰撞:myscrolls.com 为 2017 年 NameBright/HugeDomains 囤售停放域(可买断非经营者);MS Store 有低知名度「MyScrollsDemo」(视频/粉丝类 demo)。

**否决理由(按权重)**:
1. **ZeniMax 标准字 SCROLLS 在权 + 习惯性执法**:ZeniMax(Microsoft 旗下)2024 年官方商标清单仍单列标准字 **"SCROLLS"**(独立于 THE ELDER SCROLLS 家族);v. Mojang 案结局=「Scrolls」商标所有权全部转归 ZeniMax(2012 和解,Mojang 仅获单款游戏回授许可,该游戏 2018 年已改名 Caller's Bane);执法史含对粉丝小项目 Fortress Fallout 发 C&D、逼独立游戏 Prey for the Gods 改拼写。MyScrolls 的 dominant element 恰是裸复数词 SCROLLS,类 9 可下载软件与其注册同大类——opposition/C&D 属合理预期而非尾部风险。对照:Scrolleria 是熔铸造词(scroll+eria,SCROLLS 不独立成词素),暴露差一个数量级。
2. **"MY-" 前缀救不了场**:USPTO/EUIPO 实务均视 MY+名词为 possessive 弱构词,近似比对中折权(EUIPO BoA《Overlap in a weak or non-distinctive element》;Book My Event 案法院认定 "BookMy" 不可独占)。法律观感 ≈ SCROLLS + 弱前缀,第六轮 Scroll 族否决理由(描述核心交互、显著性残)全额继承。
3. **exact 同名图像软件在售**:itch.io「My Scrolls」(Smart Games Production,$4.99,WEBTOON 图片批量转竖向滚动视频)——同名+软件类+图像处理相关,半休眠但 ~209 天前仍有更新,是对方先用抗辩素材。
4. **SERP 锁死**:"my scrolls" 被 Elder Scrolls/D&D 玩家语料(Spell Scroll、Skyrim Scrolls 攻略)完全统治,零空位;品牌气质上 My- 前缀属 Web2.0 代际印记(MySpace 系),与「极致性能专业资产管理」定位相悖。

商标索引嗅探(justia/trademarkia 镜像 site: 检索):MYSCROLLS/MY SCROLLS 任何类零注册零申请(中等置信,镜像可用性已用 THE ELDER SCROLLS Reg 3421731 反向确认非盲区)。

## 2. 功能缺口清单(按用户价值排序,前后端合并)

1. **人脸框校对入口(人脸闭环最大缺口)**:查看器 overlay 纯展示(pointer-events:none),无法点脸命名/改派/移出/标误检;校对只有批量审批面板一条路,单图纠错须绕行。后端五命令齐备,纯前端接线活。
2. **失败面可见性 + 非破坏重试**(A11+F9+前端):AI 摘要无 error 计数、Error 项永远计入 pending(进度到不了 100%);face 进度刻意含失败(到 100%)反而掩盖失败存在;两侧都无失败清单查询、无「仅重试失败项」——face 侧唯一恢复手段是**销毁全部标注**的 restart。建议:`retry_failed_{ai,face}_items` 命令 + 摘要补 error 计数 + 设置页/工具卡失败入口。
3. **误检桶(is_ignored)整条特性不可达 🟠【亲证】**:schema(V8)、recluster 保护逻辑、list 过滤全部建好,但全仓**无任何写入口**(IPC 无命令、前端无 UI;`set_person_hidden` 只管 is_hidden)。补一条 `set_person_ignored` 命令+人物墙右键即激活既有全部机制。
4. **语义结果逐项相似度不可见**:徽章逻辑困在死组件 SemanticResultCard(U13,268 行零引用)里,现行画廊注入路径无任何相似度展示——用户无法判断结果质量、难理解阈值滑杆作用对象。配套:limit=1000 截断无提示(U21)、matchCount 只写不读(U14,可用于「共 N 命中,阈值后显示 M」)。
5. **以图搜图**:基建已齐——semantic_search_with_vector 已把打分半段与查询向量来源解耦(search.rs:111 注释),ai_embeddings 现成有每图向量;缺「按 item_id 取向量作 query(排除自身)」一条命令+前端入口,零推理成本。
6. **人物墙管理面**:封面手动重选(仅自动 quality 最高)、显示已隐藏人物开关(隐藏后 UI 不可逆)、排序/过滤(脸数/名字)、「未命名簇 ↔ 已命名人物」的命名建议与相似簇合并建议(碎片化修复现只有全量 recluster 一把大锤)。
7. **聚类阈值/质量下限 UI 可调**:`face_same_threshold`/`face_min_quality` config 键已预埋(face_cluster.rs:51-58,服务「实测比较」约束),但全仓无 IPC/前端写这两个键——「不重编译调参」目前等于手改 DB。语义侧有阈值滑杆,聚类灵敏度无任何旋钮,不对称。配套:det_score_thresh 不在 override 面内。
8. **人脸模型切换 UI**:后端 gated `set_active_face_model` 已交付(verified 门+名册隔离),FaceModelLibrary 只读展示(注释自认「切换仍未开放」)——todo G1-1 已载归 Part5,列此防遗忘。
9. **进度推送**:无 event/Channel(下载侧有先例),前端 2s 轮询(成本见 04-P17);批粒度 emit 一并解决状态闪回(U11)与状态栏人脸指示(U9)。
10. **模型下载不可取消**:后端无 CancellationToken/取消命令,前端无 cancel 通路;GB 级误点只能等(断点续传使代价可控)。配套:下载进度组件本地态(U10)。
11. **unassign 不持久**:移出不记负样本,下次 recluster 大概率吸回(reject 才挡);前端把「移出」呈现为终局操作会误导。裁决方向:unassign 顺带记 rejection,或 UI 文案明示区别。
12. **英文/异构 CLIP**:TokenizerKind 仅 BertWordPiece(OpenAI BPE/SigLIP SP 未实现,ai-core 已注明二阶段预留);ViT-H/14 为占位登记。
13. **宠物脸**:YuNet 仅人脸,schema 无类别列;远期。
14. **协议层**:取消/进度帧缺失(取消=杀进程,W8)、GpuUnavailable 无发射点、Hello.max_blob_len 与 SessionReadyBody.caps 契约字段闲置——随下一次协议版本升级顺带清理。

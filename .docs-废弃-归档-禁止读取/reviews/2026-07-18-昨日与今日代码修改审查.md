## Findings

### P1

1. `src-tauri/src/derive/pipeline.rs:97`：🔴 旧派生任务取消后收尾会无条件 `cancel_derivation()`，而 `start_derivation` 在 `src-tauri/src/ipc/derive_commands.rs:85` 取消旧轮次后随后安装新 token；旧任务稍后退出时会取走并取消新 token，使刚重启的“视频封面/关键帧提取”静默停止。修复：仿照 `finish_ai_analysis(generation)` 为派生 token 加 generation，并只 compare-and-clear 本轮 token；补“旧轮次 finish 晚于新轮次 start”的确定性测试。（本轮 `c73f8e0a` 新增手动重启入口，使既有竞态进入直接用户路径。）

2. `src-tauri/src/ipc/thumbnail_commands.rs:921`：🔴 全量/增量缩略图旧轮次被取消后仍发布全局 `cancelled` 快照，并在 `:936` 无条件清空 `thumb_gen_token`；用户停止后立即重启时，旧轮次会覆盖新轮次的 `running` 状态并清掉其可取消句柄，新任务继续跑但状态显示已取消且无法再停止。修复：为 token、快照和事件带 generation，只有活动轮次可发布终态及清槽；补 stop→立即 start 的乱序收尾测试。

3. `src-tauri/src/ipc/scan_commands.rs:383`：🔴 重链接先自动提交 `scan_roots.path`，再分别 upsert volume、绑定 `volume_id`；后续任一步失败都会返回错误，但根路径已经永久改变，且 data version / tree cache 不失效，形成数据库部分提交和前后端认知分裂。修复：先在写锁外解析卷信息，再以单个 SQLite transaction 完成路径、卷、绑定和结果读取，commit 后再失效缓存；补第二/第三步故障注入回滚测试。

4. `src-tauri/src/reader/text_index.rs:342`：🔴 新增的章节上限只会在“行边界”切分，单行大于 30K 字符时仍生成一个无限大的 section；minified JSON、base64 或单行日志 TXT 仍可把分页 multicol 推入本次修复要避免的内存放大路径。修复：对超长单行按字符/源字节安全切分并保持 byte offset 正确，或让 TXT 同样强制切到 scrolled；补单行 256K+ 字符测试。

### P2

5. `src-tauri/src/ipc/scan_commands.rs:319`：🟡 重链接在确认目录存在、查重和抽样匹配之前就把目标目录加入当前进程的 Tauri asset protocol scope；任何 `relink_not_a_dir`、`relink_path_taken` 或 `relink_mismatch` 都会在本次应用生命周期内留下不属于媒体库的读取授权，扩大 WebView 可读面。修复：全部校验及数据库 transaction 成功后再授权；若 API 支持，成功迁移后撤销旧根授权，并验证失败路径不改变 scope。

6. `src-tauri/src/ipc/derive_commands.rs:101`：🟡 “全量重新提取”复位数据库失败时只记 warning，随后仍启动流水线并向前端返回成功；用户请求重做已完成项，实际却只处理原有 pending 项。修复：让 `reset_derivations_by_kinds` 的错误向 IPC 传播，复位失败不得启动；补 DB error 返回稳定 IPC error 的测试。

7. `src-tauri/src/video/media_foundation.rs:400`：🟡 `select_video_only` 先关闭全部流，再忽略重新开启视频流的失败；与注释承诺的“失败照常全选”相反，部分不支持精细 stream selection 的源会留下全流禁用会话并解码失败。修复：第二步失败时回滚 `ALL_STREAMS=true`，或只有在完整切换成功后采用选择结果；以不支持单流选择的 source/mock 覆盖回退。

8. `src/components/sidebar/sections/FoldersSection.vue:1365`：🟡 重链接、刷新 roots 和后续增量扫描共用同一个 `try/catch`，扫描启动失败会落入 `relinkFailed`，即使路径已成功迁移且 success toast 已显示；用户会收到互相冲突的“成功/失败”并可能重复迁移。修复：把重链接提交与 follow-up scan 分成两个错误边界，后者明确提示“重链接成功、重扫失败，可重试”。

9. `src/components/media/ContentViewer.vue:721`：🟡 每次旋转都 fire-and-forget 一个独立写请求，既不串行/合并 latest value，也不处理拒绝；快速连点时后端任务取得 DB 锁的顺序不保证等于点击顺序，旧角度可能最后落库，单次写失败也会让当前乐观角度在重开时静默回退。修复：按 item 串行或 debounce 为 latest write，捕获失败并回滚/提示；补乱序 Promise 完成与写失败测试。

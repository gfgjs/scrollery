## 1. 实施结果

画廊虚拟滚动收敛为 **bucket 单引擎**(`src/composables/useBucketVirtualScroll.ts`);方案 A(线性平移引擎)与其运行时开关整体退役。

- 删除:`useVirtualScroll.ts`(439)、`useVirtualScroll.spec.ts`(533)、`galleryLayoutSource.ts`(74,布局源内联进引擎直接装配 `useJustifiedLayout`)。
- 引擎层去掉 `bucketActive` 开关、双引擎互斥、引擎切换 watcher(滚动位回设),以及 `visibleRows`/`renderAnchor`/`logicalToPhysical`/`spacerHeight`/`updateVisible` 等方案 A 专属读数面。
- 设置链删除:`uiStore` ref/setter/配置读回、`DynamicSettingControl` 绑定、`settingsMap` 条目、`SettingsView` 分组键、zh/en 文案、harness `&bucket` 参数。
- **保留**:DOM / Canvas 两种渲染、H-Lab(`useHVirtualScroll` 仅更新失效注释，功能未改)、全部选择模式解耦、MediaScrollbar 与 minimap 轴链路。
- 全局 Canvas 能力保护沿用原值:`CANVAS_MAX_TOTAL_HEIGHT = 10_000_000`(引擎本地常量,判据仍是 `!isIOSLike && totalHeight ≤ 上限`),**未因删旧引擎放宽超大库 Canvas**;`resolveSafeMax` 的 localStorage debug override 随旧引擎删除。
- 实际提交 `3983327e`：28 个前端文件新增 191 / 删除 1,581，**净减 1,390 LOC**（含测试与注释）。后续基准 URL 去掉已退役开关，行数不变。

`updateVisible(force)` 的处置结论:bucket 无对应物且不需要——段表由引擎的 `layoutVersion` watch 自驱重建。因此删的是调用而非留下空包装(`useGallerySelectionOps`/`useGalleryKeyboard`/`settleRouteReturnLayout`/`onMounted`/`onGalleryReactivate`/`useViewportDimPriority.refresh`/`useGalleryTauriSync`)。

## 2. 等价性与新增表征

当前主画廊接线统一使用 bucket；其 B3 段级映射承接长坐标，输入处理区分 wheel/键盘/触摸。下列行为已有单元或 fixture 证据；尚未覆盖的真实平台交互见 §4，不据此宣称所有环境下完全等价：

- 引擎 spec 重写为 `canvasCapable` / `canvasActive` / `canvasMode` 透传(原 `bucketActive` 用例按语义删除)。
- bucket spec 新增两条:**映射态长距恢复**(`scrollToLogicalY` 落点 + 锚差自洽、覆盖段存在保证首帧无空洞)、**换代总高缩水回非映射态**(anchorDelta 归零、spacer 随新几何)。
- `whenSettled` 的「引擎停用释放等待者」改为「空愿望集释放等待者」。
- 单测中删除 `useVirtualScroll.spec.ts` 全部 8 个主题;其中 `padding 计算`/`canvas 取行窗`/`SAFE_MAX 边界`/`wheel 惯性补偿` 的等价面已由 bucket spec 现有用例(自适应段高、canvas 取行窗 §4.3 S3、映射态手势分类)覆盖。

## 4. 已知边界(不可外推)

- **`pageExceptions` 存在已知 UI harness 无 Tauri runtime 的 listener 异常**:dev harness 下 `scanStore.restoreThumbGenProgress` 经 `listen()` 触发 `UI harness 无 Tauri runtime`,**收敛前后两份样本一致**;它不影响滚动指标录制,但说明该 harness 未覆盖真实事件桥。
- **`coldCellFrames = 0` 与 ~144fps ≠ 原生 GUI 全绿**:该配置(10k 条 / rowHeight 200 / v=1.5px/ms)未触达瓶颈,只可作 bucket 侧回归锚点;headless Chrome 非 WebView2,绝对值仅作分层定位与 A/B 相对比较。
- **高坐标/映射态仅有单元级证据**:总高 > 16M 的段级映射、长距恢复、重锚/偿债只在 `useBucketVirtualScroll.spec.ts` 的伪造容器上验证;fixture 无法构造该规模,**真机大库仍未测**。
- 未覆盖:窗口缩放、时间轴跳转、布局切换、跨视口选区恢复、弱机。
- 未做 A/B 对比:不主张「方案 A 更差」,退役依据是功能超集 + 单引擎收敛,不是性能比较。

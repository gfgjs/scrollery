# 全仓开源前屏蔽与收费组件边界

> 🔴 **2026-09-14 注**：本文以 MPL-2.0 为现行第一方许可；该结论已被 AGPL-3.0-only ＋单独商业授权的决议取代。
> 底层结论（不能把收费等同于源码必须屏蔽、公开算法不能宣称独占、既有许可义务不因文件挪动消失、
> 官方签名/更新/支持才是商业价值）仍然有效，正文按当日证据保留。
> 现行规范见 [AGPL-3.0-only 与单独商业授权决策 brief](../decisions/2026-09-14-决策brief-AGPL-3.0-only与单独商业授权.md)。

## 结论与口径

审查基准：2026-09-12，本地 HEAD `b2d7f49d` 及当时工作树。当前有其他任务的未提交修改，本报告只对所核实版本负责。本次不改产品代码、许可、付费组合，不执行拆仓、删除历史或公开发布。

现行第一方范围为前端、Rust 主机、现有随附 worker 与授权实现统一 MPL-2.0。不能将“收费”直接解释成“源码必须屏蔽”。现有源码与第三方开源算法也不能被描述为只有购买者才能取得的独占技术。未来新建的独立商业组件可另定许可，具体边界须与主程序声明一致。

**建议维持私有 canonical → 经过审查的公开镜像，不将当前私有 Git 仓库直接改成 public。公开前先处理过滤遗漏与推送前检查，再核清第三方载荷。**

## 3. 私仓安排建议

采用“一个商业运营私仓，真正出现独立商业实现时再建组件私仓”的轻量结构；以下名称只是建议，没有创建任何仓库。

| 仓库/存储 | 放什么 | 边界 |
|---|---|---|
| 现有公开 `scrollery` | 现有主程序、授权客户端、验签、公钥、插件协议、现有 worker、合法第三方材料、公开构建和测试 | 按现行 MPL-2.0 边界发布；开源软件可修改和自编译，官方服务权益另行验证。 |
| 现有私有 canonical | 内部计划、审查、同步配置、尚未发布变更 | 保持既有开发方式，不把内部文档迁入公开产品仓。 |
| 建议 `scrollery-commercial-ops`（私有） | 后续支付回调/订单/退款/授权签发服务实现，官方发行编排、商业分发权限配置模板、合同和运营规则 | 当前需要隔离的是运营能力。签发工具源码本身可以公开；是否迁工具取决于维护方式。真实秘密和客户数据库不入仓。 |
| 未来 `scrollery-commercial-components`（私有） | 新开发且权属明确的独立商业 worker/插件实现，独占模型的训练/转换实现，企业或云服务实现 | 有真实组件再拆。不能通过挪动已有 MPL 文件抹去既有许可义务；也不能将第三方公开权重换名当作自有独占模型。 |
| 受控对象存储/制品库 | 商业组件构建包、合法持有再分发权的专有模型及配套证明 | 大载荷适合制品存储，私有 Git 不是分发权限系统。购买鉴权、签名真实性与内容保密是不同责任。 |

Mozilla 官方说明 MPL 是文件级 copyleft，可与独立专有文件组合；对已覆盖文件的修改与分发仍有源码义务。是否能将既有代码另行许可还依赖完整权属与贡献授权，不能仅据有一份 CLA 文档认定授权已齐。[Mozilla MPL FAQ，Q8–Q11](https://www.mozilla.org/en-US/MPL/2.0/FAQ/)

## 4. 专项扫描与收费代码证据

### 4.1 敏感信息与本地历史

- 专项代理对 2503 个跟踪文件的指定文本范围、103 个未跟踪文件、当时 41 个修改文件新增行，以及 20 个本地 refs / 1927 次提交做常见密钥模式扫描和历史 pickaxe 检查。全对象路径名检查覆盖约 2.25 万对象。
- **在该扫描口径内没有发现高置信真实凭据。** 模式包括私钥 PEM 头、常见平台 token、云访问键、Webhook/JWT、认证头。vendored Vditor、第三方许可正文、NOTICE 和 lockfile 等未纳入该轮普通文本模式全扫；历史压缩产物曾有宽模式误报，经定位排除。
- 本机 `.release-keys/`、`.internal-signing/`、`.dev-registry/` 确有私钥文件，已确认被 Git 忽略，未读取密钥值；历史文件名检查未发现这些私钥曾入库。此结论不能扩张为“整个磁盘没有秘密”。
- 历史出现的敏感外观 keyset 文件经字段核查均为公钥集合。没有把公钥、脚本读取私钥的代码、CI 的 secrets 引用误报为私钥泄露。
- Git 历史包含个人作者/提交者邮箱；docs 内另有机器路径和真实素材库派生的条目 ID/缓存 hash，例如 `docs/worklogs/2026-08-16-Canvas缩略图加载渲染性能优化/ab-stage2/R1v2-backup.json`。当前投影排除 docs，但直接公开私有仓库会暴露这些历史与内部资料。
- 本机没有 gitleaks/trufflehog/git-secrets/detect-secrets；本次为模式扫描，**不等价于专用扫描器、熵检测或二进制内容审计**。被忽略目录只检查相关路径/忽略状态，未全面扫描；未读取真实密钥，也不需要为了审查而复制它们。

- [InsightFace 官方许可说明](https://github.com/deepinsight/insightface#license) 区分 MIT 代码与受非商用研究限制的训练数据/模型；免费提供应用或允许手动下载也不自动取得商用权。

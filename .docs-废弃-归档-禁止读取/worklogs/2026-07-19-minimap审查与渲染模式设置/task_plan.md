## 关键决策

| 决策 | 理由 | 候选 ID |
|------|------|---------|
| 默认保持现有缩略图行为,新增用户可选的纯色块模式 | 避免升级后悄然改变既有视觉,同时给重视即时性的用户零图片加载选项 | |
| 启动配置水合前先守在纯色块模式 | 避免持久化为“仅色块”的用户重启时被默认值抢跑图片请求;缺省配置水合后仍恢复既有缩略图默认 | |
| 所有非空画廊均可使用 minimap，已有 scrubber 时默认时间轴并提供会话内切换 | 保留既有默认视觉，同时兑现用户允许的日期/分组视图选择权，不新增持久化配置 | |
| 微图失败最多额外重试 2 次（400ms、1200ms），不触发主缩略图自愈 | 覆盖瞬时 fetch/decode 失败，同时对永久 404/缓存驱逐保持严格 IO 上限 | |

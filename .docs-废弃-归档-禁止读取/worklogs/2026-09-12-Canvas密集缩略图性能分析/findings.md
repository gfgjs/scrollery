# 发现

- 当前 Canvas 主组件已拆出 useCanvasThumbPipeline，与旧材料的路径地图有差异。
- draw 已按 visibleRowRange 二分裁剪，遍历当前可见行；仍每次清整屏并重绘可见格。
- 当前工作区含其他会话修改，后端 serve.rs 和基准脚本也在其中；以当前源码为证据，不混入本轮交付。
- 三个获授权提供商分别承担加载、后端、虚拟化/基准的只读审查。

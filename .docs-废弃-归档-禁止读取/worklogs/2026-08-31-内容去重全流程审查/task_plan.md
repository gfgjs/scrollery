## 错误账
| 错误 | 尝试 | 解法 |
|------|------|------|
| `npm test -- --run ...` 将 Vitest 参数误传为 npm 配置 | 首次聚焦前端测试命令失败，报 `EUNKNOWNCONFIG` | 改用 `npm test` 全量或直接调用 `node_modules/.bin/vitest.cmd run ...` |
| 三路 Luna(Max) 复核代理均遇服务端 `429 Too Many Requests` | 重试后仍无可消费输出 | 不把代理结果计作独立证据，改由主代理逐行复核并执行全量门禁 |
| `worklog-kit check` 首次发现本轮状态分片缺少工作线实体 | 运行文档门禁后按提示补建 `docs/lines/内容去重全流程审查.md` | 本轮新增结构问题消除；剩余 4 项来自既有 2026-08-25 closeout |

## 关键决策
| 决策 | 理由 | 候选 ID |
|------|------|---------|
| 基准录制期间隐藏面板并停止响应式刷新，录制结束后再汇总 | 避免面板自身 DOM 更新和绘制污染被测帧 | D-001 |
| 采集核心使用非 Vue 单例与固定容量缓冲区，UI 只消费停止后的快照 | 避免每帧响应式分配和 watcher 开销 | D-002 |
| 不创建第二个 Tauri WebView 性能窗口 | 第二个渲染进程会引入额外 CPU/GPU 干扰 | D-003 |
| 绝对性能以 Release + DevTools 关闭的静默录制为准，DevTools 只用于异常定位 | 将定量回归与根因分析分离 | D-004 |

## 错误账
| 错误 | 尝试 | 解法 |
|------|------|------|
| Windows 沙箱 ACL 注入导致普通 exec 无法启动 | 并行及串行只读命令各一次 | 仅对必要仓库检查使用获批的提升权限，不绕过外部记忆拒绝 |
| 内建 apply_patch 与普通进程均在沙箱初始化时报 apply deny-read ACLs | 对工作区补授 WRITE_DAC 后重试两次 | 经用户授权改用 git apply --check → git apply 精确 unified diff，并逐次重读 |
| 应用内浏览器 Node 内核同样被 ACL 初始化终止 | 按 browser skill 初始化一次 | 不改用外部自动化冒充；将 UI 实测标为环境阻塞，保留静态与构建验证证据 |

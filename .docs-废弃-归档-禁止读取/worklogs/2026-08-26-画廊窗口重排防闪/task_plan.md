## 关键决策

| 决策 | 理由 | 候选 ID |
|------|------|---------|
| 优先保留旧布局并原子替换，不在布局版本变化时清空 bucket | 直接消除可见空窗，改动面小于重写渲染层 | D-001 |
| 计算队列只发布最后一个待处理结果 | 窗口连续变化时中间布局没有视觉价值，只会制造额外换代 | D-002 |
| Canvas 尺寸更新由组件内统一调度，resize 期间允许延后 backing store 精确适配 | 避免每个 ResizeObserver 回调清空 backing store | D-003 |

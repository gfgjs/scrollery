# worklogs — 长任务工作记忆归档

本目录存放**已收口长任务**的工作记忆三件套(`task_plan.md` / `findings.md` / `progress.md`),来源是自研 `/planning` skill(`.agents/skills/planning/SKILL.md`;承 Manus 式「文件即磁盘工作记忆」思想:上下文窗口=易失 RAM,文件系统=持久磁盘。前身 planning-with-files 插件已于 2026-07-11 弃用)。

## 为什么单列一类

- **执行期不在这里**:任务进行中,三件套活在 `docs/planning/<日期>-<任务名>/`(入库随 git 同步以支持换机续作;copybara 排除面内不进公开镜像;中文任务名可用)。
- **收口即归档+蒸馏**:任务收官时,按「收口即处置」仪式把三件套 `git mv` 进 `worklogs/<日期>-<任务名>/` 留档,**并逐候选蒸馏耐久价值、写 `closeout.md`**(见下节);归档后三件套正文冻结(与 archive/ 同规,仅文首横幅可追加)。
- **与 reviews/ 的区别**:reviews/ 是我方对代码的**审查结论**(带治理 frontmatter、受全量门禁);worklogs/ 是任务执行的**过程记录**(skill 模板产出,带模板 frontmatter,但内容为过程快照,故门禁对三件套豁免 frontmatter 与断链检查)。

## 收口契约(closeout.md,worklog 入库结构门)

每个归档任务目录**必须**含 `closeout.md`(2026-07-12 [融合评估方案](../designs/2026-07-12-工作记忆与文档体系融合评估方案.md) §5-#1;模板见 skill 文末):三件套两张声明表(findings 候选表 / task_plan 决策表)登记的耐久候选 `F-*`/`D-*`,在 closeout 处置表中**恰好各一行**。2026-09-15 起取消文档 CI 门禁，以下结构约定可按需用 worklog-kit check 手动检查：

- 候选全覆盖、不重、无未知 ID(声明源仅限两张表的「候选 ID」列,叙事提及不算)。
- `disposition ∈ experience|decision|design|runbook|completed|todo|code|test|no-promotion`。
- target:docs 侧 `repo:<仓根相对路径>` 且验存;`todo` 以 `.worklogrc.jsonc` 的 todo 处置为准——本仓为 generated 档(D-014):target=`repo:docs/status/<slug(任务 line)>.md` 并同步 todo.md 线索引表;未启用的 fixed 档才固定 `repo:docs/todo.md`;`code`/`test` 用冻结引用 `repo:<路径>@<commit 短hash>`(只验 grammar,不验存在);`no-promotion` 填 `—` 且必须给 N/A 理由。
- `verified` 只接受 `yes`。

**冻结边界**:三件套正文冻结;closeout 语义列(候选 ID/disposition/理由)冻结;仅 docs 侧 target 因目标文件迁移可在**同一移动 commit** 更新(target 消失即门禁红,机械强迫修链);code/test 冻结引用永不回改。此门只验结构——不判断任务何时该收口,也不证明候选选得全。

## 门禁豁免

docs 门(worklog-kit check;其前身仓内脚本 `tools/check_docs.mjs`、`tools/check_docs_index.mjs` 已于 2026-07-21 移除,裁决 U-13)对 `worklogs/**` 与 `planning/**` 下的 `task_plan.md` / `findings.md` / `progress.md` 豁免 frontmatter 与断链检查(内容为过程快照,内链会随源码重构自然腐化)。**`closeout.md` 与两目录内手写文件(README/索引/验收清单等)不在豁免名单**,照常受治理(需合法 frontmatter:status/type/created)。

## 命名

`worklogs/<YYYY-MM-DD>-<任务名>/`,日期取任务**创建**日(即三件套 `created`/原 planning 目录前缀;2026-08-24 裁决订正——收口日命名会让同日批量收口的目录全撞同一前缀,43 线曾因此全冠 2026-08-14 并全仓订正);任务名尽量与 todo.md 线索引表工作线对齐,便于回溯。

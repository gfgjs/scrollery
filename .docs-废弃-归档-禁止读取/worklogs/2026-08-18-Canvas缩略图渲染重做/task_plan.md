## 关键决策
| 决策 | 理由 | 候选 ID |
|------|------|---------|
| Canvas 专项只恢复缩略图管线与绘制生命周期 | 备份补丁同时混入路由、查看器、侧栏和选择状态机，整体恢复曾导致运行时回归 | D-001 |
| 性能结论须由当前真实窗口或可复现基准支持 | 旧审查明确区分既有 A/B、代码事实与待测假设，不能把历史推断重复写成实测 | D-002 |
| 先补契约测试，后写组件代码 | Canvas 异步回调和绘制代次容易在表面正常时隐藏旧请求/资源泄漏回归 | D-003 |
| 首批只处理 KeepAlive 失活和不可取消解码的所有权 | `MediaGridCanvas` 的 298 行备份差异中，零尺寸保护与异步回包拒绝可脱离路由 token；其余 ready/resize/interaction gate 不可脱离宿主状态机 | D-004 |
| 侧栏返回只提取几何守卫 | 旧补丁虽有对应实现，但与 gallery-ready、路由水合和查看器关闭状态机混在一起；本批只保留“过渡冻结、最终宽度判定”的最小契约 | D-005 |
| 不以查看器延迟离场遮挡未就绪画廊 | 用户实测该方案产生明显迟滞；应保留画廊现有帧并使查看器成为路由驱动覆盖层 | D-006 |

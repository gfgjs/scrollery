## 关键决策
| 决策 | 理由 | 候选 ID |
|------|------|---------|
| 只优化当前 Canvas 路径，不改变产品交互与 DOM fallback | 将性能收益与功能重构解耦，降低回归风险 | |
| 画廊用二分窗口替代全挂载段扫描 | 布局行已按 y 有序，可把每帧复杂度降到 `O(log n + 可见行)` | D-001 |
| 右侧轴缓存静态层，动态层逐帧合成 | 绝大多数密度图形不随滚动变化，可把滚动帧从重画全部节点降为一次位图合成加少量动态绘制 | D-002 |

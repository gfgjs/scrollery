## 关键决策

| 决策 | 理由 | 候选 ID |
|------|------|---------|
| 正常切图由真实加载/解码完成驱动，不再由固定透明度和定时器驱动 | 固定 200/250ms 与实际 IPC、IO、解码时长无关，首次加载必然暴露黑底 | D-001 |
| 错误目标必须提交错误态，不把旧图改绑为新 URL | 复用同一 img 会在请求失败前重绘上一张位图，并受新条目的 transform/reset 影响 | D-002 |
| 跨条目切换立即撤下旧帧，以目标缩略图或中性加载态等待；仅同条目 ICC 换源保留已提交图 | 旧帧即使稳定不闪，也与已经切换的条目语义不一致；目标占位既避免误导，也能掩盖完整图解码时间 | D-003 |

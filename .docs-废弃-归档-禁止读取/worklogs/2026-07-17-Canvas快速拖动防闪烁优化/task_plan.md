# 任务计划:Canvas快速拖动防闪烁优化

## 目标
消除主页 Canvas 画廊快速拖动滚动条时因空白帧与真实缩略图帧极速交替造成的强烈闪烁，同时保持滚轮极速滚动无明显顿挫，并通过真实图库实测裁决方案。

| Canvas 可见区快滚持续加载；视口外预取关闸期**收缩为仅前向(1.25 屏、后方 0)而非整体停取**(2026-07-17 阶段 6 修订原「仍关闸」语义) | 用户明确要求快速拖动正常显示缩略图;headless 基准实证「关闸=停取」正是稍快速换图波根因(burst 4911→~530);64 全局槽和大跨度旧 fetch 取消继续控制任务量 | D-002 |
| 冷区清屏与无平均色占位统一使用主题化中灰 | 第二版仍明显闪烁；不改变加载吞吐的前提下，先缩小底色与真实图之间的明度跳变 | D-003 |

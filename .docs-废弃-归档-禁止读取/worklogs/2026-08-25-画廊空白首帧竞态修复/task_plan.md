# 画廊空白首帧竞态修复

## 目标

修复 Canvas 画廊偶发首帧空白、滚轮后才显示的问题，并用回归测试锁定已定位的 rAF 代次竞态。

## 计划

- [x] 核对当前 Canvas 调度实现与脏工作树变更
- [x] 实现代次感知的 rAF 调度
- [x] 增加首帧挂载/激活时序回归测试
- [x] 运行聚焦测试与静态检查
- [x] 更新状态文档并归档工作记录

## 结果

已在 `CanvasRafScheduler` 中记录待执行 rAF 的 generation；同代次请求继续合并，跨代次请求取消旧帧并重排当前帧。新增回归覆盖 generation 0 排帧、`activate()` 切到 generation 1、旧回调晚到及同代合并。

验证：helper 测试 64/64、全量 Vitest 1579/1579、`vue-tsc --noEmit`、相关 ESLint、生产构建均通过。

## 关键决策

| 决策 | 理由 | 候选 ID |
|------|------|---------|
| 抽出只负责 rAF 状态的 `CanvasRafScheduler` | 组件仍保留绘制逻辑，纯 helper 可在当前 Node Vitest 环境复现生命周期竞态 | D-001 |
| 待执行帧同时绑定 generation，跨代次取消并替换 | 旧帧回调会因生命周期失效而跳过绘制，单独保留 `rafId` 会再次复现空白 | D-002 |
| 用 lifecycle 驱动的时序测试锁定旧回调晚到与同代合并 | 覆盖根因时序，同时不需要改变测试环境引入浏览器 DOM | D-003 |

## 验收

- 激活导致 render generation 变化时，不再复用旧代次待执行帧。
- 当前代次至少会排入一次绘制，且已有同代次帧时仍保持合并。
- 相关单测通过，未引入无关文件改动。

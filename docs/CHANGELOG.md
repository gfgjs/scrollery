## [0.1.0] - 2026-10-13

### 变更

- **移除读屏/无障碍标注**:删除 ARIA/role/alt/live region 等读屏语义与减少动态效果适配;保留键盘操作、焦点陷阱与 inert 焦点隔离。
- **产品更名 Scrollery**(原工作代号 picasa-next):应用标识符改为 `com.scrollery.app`,凭据库服务名改为 `scrollery`,数据库文件更名 `scrollery.db`。
- **桌面工作流**:移除移动端适配,以鼠标、键盘和触控板操作为主;更新工程配置与开发文档。

### 新增

- **画廊浏览**:图片 / 视频 / 文档 / 音频统一媒体网格;两阶段扫描(秒级出图 + 后台 EXIF/XMP/Live Photo 补全);后端两端对齐 / 宫格布局 + 大库分段虚拟滚动(自研逻辑滚动条)。
- **缩略图管线**:原生缩略图 worker 与主应用解耦,按条目识别版本化产物,统一 EXIF 方向处理;派生产物原子落盘;ThumbHash 模糊占位。
- **AI 语义搜索**:Chinese-CLIP 嵌入(ONNX Runtime / DirectML,运行于独立 ai-worker 子进程)+ 常驻 f16 向量缓存 + rayon 余弦打分。
- **人脸识别**:检测 / 嵌入 / 增量聚类 / 命名与合并。
- **资产组织**:收藏夹、收藏 / 评分 / 色标、文件夹树、批量移动 / 复制 / 删除(回收站)。
- **冷门格式插件平台**:签名 registry + 插件商店(安装 / 升级 / 修复 / 激活 / 卸载),首发 PSD;渠道物理门控(direct / MsStore / Steam 骨架)。
- **离线卷 UX**:离线灰显 + 角标、已知卷面板(改名 / 忘记)、重连自动恢复。
- **国际化**:简体中文 / 英文。
- **文档阅读与编辑**:Markdown 原位编辑、代码块复制、库内相对链接与标题跳转;PDF 文字选取。
- **音频与画廊**:音频倍速播放与续播;可配置的实验性 Canvas 混合选项。

### 修复

- 外部移动或改名后保持库内资产身份并同步文件树,修复扩展名改名后的分类与刷新。
- 阻止损坏备份参与轮转,改进同秒备份排序;修复文件移动或复制提交失败后的回滚与缓存身份。
- 修复 Markdown 跨格式粘贴、保存刷新顺序、长表分页裁切,以及视频预加载、倍速设置和缩略图尺寸问题。
- 修复缩略图信息重叠、Canvas 悬停跳变及森林主题的分隔线与焦点轮廓。

### 预览版使用说明

- 本次发布提供 Windows x64 的 MSI 与 EXE 安装包。
- AI 搜索需要先下载模型并完成图片分析。
- 图片高级编辑、OCR 和 PSD 引擎需在“功能与插件”中分别点击“免费激活”,并准备对应插件或模型;无需注册码或联网激活验证。
- 影像增强所需模型尚未交付,降噪、去 JPEG 伪影和超分暂不可用。

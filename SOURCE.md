## Where to get the corresponding source

The project distributes official builds from its public repository:

- Source repository: https://github.com/gfgjs/scrollery
- Releases: https://github.com/gfgjs/scrollery/releases

These links are the project's source and release entry points for official
builds. Whoever conveys a build in object code form is responsible for making
the Corresponding Source for that exact version — and the material needed to
build and install it — available before or with that conveyance, as AGPL-3.0
section 6 requires. For an official build, that Corresponding Source is the
revision the build was produced from.

The Corresponding Source is not limited to the first-party code in this
repository: it covers everything the AGPL requires for the work as conveyed,
including build and installation scripts and the source of components that are
part of the work. Third-party components keep their own licenses, and their
notices are listed in `NOTICE.md`.
